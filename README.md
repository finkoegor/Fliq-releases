# Fliq

Russian and English keyboard layout switcher for macOS. It fixes words typed in the wrong layout and converts typed or selected text with a single key.

**[Download Fliq.dmg](https://github.com/finkoegor/Fliq-releases/releases/latest/download/Fliq.dmg)**

Requires macOS 14 or later on Apple Silicon. Open the disk image, drag Fliq to Applications, then allow it in System Settings, Privacy & Security, Accessibility. Fliq updates itself afterwards.

This repository hosts releases and the update feed only.
