# Fliq

Keyboard layout switcher for macOS.

**[Download Fliq.dmg](https://github.com/finkoegor/Fliq-releases/releases/latest/download/Fliq.dmg)**

- Fixes words typed in the wrong layout: ghbdtn becomes привет
- Converts typed or selected text with one key
- English with Russian, Ukrainian, Bulgarian or Greek
- Works offline, collects nothing
- Updates itself
- macOS 14 or later, Apple Silicon

## Install

1. Open Fliq.dmg and drag Fliq to Applications
2. Open Fliq and allow it in System Settings, Privacy & Security, Accessibility

## Shortcuts

| Action | Default |
|---|---|
| Convert typed text, undo a fix, convert selection | Tap Right ⌥ |
| Convert last word | ⌃⌥W |
| Change case | ⌃⌥C |
| Turn fixing on or off | ⌃⌥F |

Change them in Settings, Shortcuts.

This repository holds releases and the update feed only.
