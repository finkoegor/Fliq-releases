# Retype

Russian and English keyboard layout switcher for macOS. It fixes words typed in the wrong layout and converts typed or selected text with a single key.

**[Download Retype.dmg](https://github.com/finkoegor/Retype-releases/releases/latest/download/Retype.dmg)**

Requires macOS 14 or later on Apple Silicon. Open the disk image, drag Retype to Applications, then allow it in System Settings, Privacy & Security, Accessibility. Retype updates itself afterwards.

This repository hosts releases and the update feed only.
